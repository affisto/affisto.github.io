개인정보처리방침

개인 개발자 임규산은 HISOHISO를 운영하면서 이용자의 개인정보를 중요하게 생각하고 관계 법령을 준수합니다.

홈으로서비스 이용약관

1. 개인정보 처리 요약

  • 회원가입이나 로그인을 요구하지 않습니다.
  • 연락처, 위치정보, 사진 또는 결제정보를 수집하지 않습니다.
  • 학습 기록과 설정은 이용자의 기기에 저장됩니다.
  • iOS·Android 앱은 서비스 이용 현황과 품질 개선을 위해 Firebase Analytics를 사용합니다. 사용자 ID, 광고 ID, 음성, 전사문과 직접 입력한 답변은 분석 이벤트에 포함하지 않습니다.
  • 마이크 음성은 먼저 기기 안에서 처리합니다. 로컬 결과로 정답을 확인하기 어렵고 클라우드 보조 검수가 활성화된 경우에만 음성 한 건이 Cloudflare와 OpenAI로 전송될 수 있습니다.
  • 이용자가 이메일로 문의할 때 이메일 주소와 문의 내용을 처리합니다.
  • 맞춤형 광고 목적의 추적이나 개인정보 판매를 하지 않습니다.

2. 기기 안에서만 처리되는 정보

다음 정보는 앱 기능 제공을 위해 이용자의 기기에 저장되며 운영자가 수집하거나 열람할 수 없습니다.

정보 이용 목적 보관 기간
학습 진도, 정답·오답, 복습 상태, 연속 학습일, 발음 약점 통계 맞춤 학습, 복습 일정 및 학습 기록 제공 앱 데이터를 삭제하거나 앱을 제거할 때까지
JLPT 단계, 후리가나, 화면 테마, 음성·속도 설정 이용자 설정 유지 설정을 변경하거나 앱을 제거할 때까지
마이크 음성, 임시 음성 버퍼, 온디바이스 인식 결과 말하기 연습의 음성 인식 및 채점 한 번의 말하기 처리가 끝나면 메모리에서 삭제
음성 인식·합성 모델과 일본어 사전 오프라인 음성 인식·낭독 및 일본어 분석 모델 또는 앱을 삭제할 때까지

음성은 화자 식별이나 생체인증에 사용하지 않으며 성문을 생성하지 않습니다. 마이크 권한을 허용하지 않아도 키보드 입력 등 다른 기능을 이용할 수 있습니다.

2-1. 클라우드 보조 음성 검수

일본어 음성 입력이 정확하게 확인되지 않는 경우, 운영자는 음성 데이터와 학습에 필요한 정보를 클라우드 저장·처리 서비스 및 OpenAI API를 이용해 재검수할 수 있습니다.

원본 음성과 전사문은 검수 완료 후 별도로 저장하지 않습니다. 서비스 운영과 부정 이용 방지를 위한 가명 처리된 사용량 정보는 90일간 보관합니다. OpenAI 공식 API 데이터 정책에 따라 API 입력은 별도로 데이터 공유에 동의하지 않는 한 모델 학습에 사용되지 않습니다.

공개 버전에서 이 기능을 활성화하기 전 전송 사실을 앱 안에서 안내하고 필요한 선택 동의를 받습니다. 동의하지 않거나 네트워크를 사용할 수 없는 경우 로컬 결과, 재시도 또는 키보드 입력을 이용할 수 있습니다.

3. 운영자가 처리하는 개인정보

서비스에는 계정 시스템이 없습니다. 다만 클라우드 보조 음성 검수, iOS·Android 앱의 Firebase Analytics와 이용자가 직접 보내는 이메일 문의 과정에서 다음 정보를 처리할 수 있습니다.

처리 항목 처리 목적 보유 기간
앱·기기 및 운영체제 정보, 앱 버전, 화면 조회, 수업·복습의 시작·완료·중단, 선택한 학습 과정과 비식별 이용 이벤트 이용 현황 분석, 기능 개선 및 오류 확인 14개월. 새 사용자 활동이 발생하면 보유기간이 재설정됨
클라우드 음성 검수 여부와 가명 처리된 사용량 정보 서비스 운영, 부정 이용 방지 및 품질 개선 생성일로부터 90일
발신 이메일 주소, 이메일 표시 이름, 문의 내용과 이용자가 직접 첨부한 자료 문의 확인, 답변, 오류 조사 및 분쟁 대응 문의 처리 종료 후 1년. 법령상 보존 의무가 있으면 해당 기간

분석 이벤트에는 사용자 ID, 광고 ID, 이메일·이름·전화번호, 음성, 전사문, 사용자가 말하거나 입력한 답변을 포함하지 않도록 제한합니다. 문의에는 주민등록번호, 결제정보, 건강정보 또는 제3자의 개인정보 같은 불필요한 정보를 적지 마세요.

4. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 판매하지 않으며 원칙적으로 제3자에게 제공하지 않습니다. 관계 법령에 특별한 규정이 있거나 이용자가 별도로 동의한 경우는 예외로 합니다.

7. 개인정보의 파기

  • 보유기간이 끝나거나 처리 목적을 달성한 전자문서와 이메일은 복구하기 어려운 방법으로 삭제합니다.
  • 법령에 따라 보존해야 하는 정보는 다른 정보와 분리해 보관한 뒤 기간이 끝나면 삭제합니다.
  • 기기 내 학습 기록과 설정은 기기의 앱 데이터 삭제 기능 또는 앱 제거를 통해 삭제할 수 있습니다.

8. 이용자와 법정대리인의 권리

이용자는 운영자가 보유한 본인의 개인정보에 대해 열람, 정정, 삭제, 처리정지 또는 동의 철회를 요청할 수 있습니다.

  • 개인정보 문의 및 권리 행사: tech@affisto.com
  • 기기 내 정보 삭제: 기기 설정에서 HISOHISO 앱 데이터 삭제 또는 앱 제거
  • 마이크 동의 철회: iOS 또는 Android 앱 권한 설정에서 마이크 권한 해제

운영자는 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 만 14세 미만 이용자는 개인정보가 포함된 문의를 보내기 전에 법정대리인의 도움을 받아야 합니다.

9. 자동 수집 장치와 추적

iOS·Android 앱은 Firebase Analytics를 통해 앱·기기 정보와 비식별 이용 이벤트를 자동으로 처리할 수 있습니다. 광고 저장, 광고 사용자 데이터, 광고 개인화 신호와 광고 ID 수집은 앱 설정에서 비활성화합니다.

맞춤형 광고를 제공하거나 이용자의 정보를 데이터 브로커에게 판매하지 않습니다. 모델 파일과 웹페이지 다운로드 과정에서는 IP 주소 같은 통신 정보가 네트워크 제공자에게 자동 전달될 수 있습니다.
